# Ingrid López — Portafolio de diseño

Portafolio digital de Ingrid López, diseñadora gráfica. El proyecto reúne una presentación personal, una selección de proyectos organizados por categorías y una sección de contacto en una experiencia web interactiva. También incluye una página de sistema de diseño y documentación de la arquitectura del contenido.
